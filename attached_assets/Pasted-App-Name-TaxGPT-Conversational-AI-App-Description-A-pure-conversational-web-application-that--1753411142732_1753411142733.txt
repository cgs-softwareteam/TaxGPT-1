App Name:
TaxGPT - Conversational AI
App Description:
A pure conversational web application that functions like ChatGPT, based on direct client feedback to avoid all forms. The user experience begins with a single chat input box. The user can type any freeform request. The application's AI is designed to first act as a data-gathering agent, conversationally asking the user for the key financial details it needs. Only after it has collected enough information will the AI generate a detailed, structured report using a special card-based format within the same chat interface.
Tech Stack:
Framework: Next.js
Language: JavaScript
Styling: Tailwind CSS
Libraries: openai, react-markdown
Key Components:
Main Page (app/page.js):
The main "use client" component.
State Management: Its primary role is to manage the conversation array (storing the history of all messages) and an isLoading state.
Layout: The layout is minimalist. It will render only two components: ChatInterface and ChatInput.
Handler Function: It will have a single handleSubmit function that takes a new message from the user, adds it to the conversation array, and sends the entire conversation history to the backend API on every turn.
Chat Interface (components/ChatInterface.js):
Receives the conversation array as a prop and is responsible for displaying the chat history.
CRITICAL RENDERING LOGIC: This component must intelligently check the content of each message from the AI (role: 'assistant') and render it in one of two ways:
1. Standard Conversational Message: If the AI's message is a simple question or a plain text response (e.g., "Thanks! Now, what is your state of residence?"), it must be rendered as a standard, clean chat bubble.
2. Final Structured Report: If the AI's message contains the special structured report (the component can detect this by searching for key markers like "✅ Scenario Title:"), it must parse and render that specific message using the required card-based layout, with prominent financial numbers, emojis, and proper formatting via react-markdown.
All user messages (role: 'user') are rendered in a simple, distinct chat bubble.
Chat Input (components/ChatInput.js):
A simple, clean form containing only a single text input field and a "Send" button, styled to feel like a modern chat application.
API Functionality:
API Route (app/api/generate/route.js):
A single POST endpoint that receives the entire conversation history array in every request.
It passes this messages array directly to the OpenAI API, allowing the AI to maintain full conversational memory.
The OpenAI API Key must be loaded securely from environment variables (process.env.OPENAI_API_KEY).
System Prompt (CRITICAL - This is the application's "brain"): The messages array sent to OpenAI must always begin with a role: "system" message containing these new, multi-phase instructions that reflect the client's latest feedback:
